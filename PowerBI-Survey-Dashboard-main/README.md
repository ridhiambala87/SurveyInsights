# SurveyInsights – Power BI Survey Dashboard

## Project Overview

SurveyInsights is an interactive Power BI dashboard designed to explore survey responses and identify meaningful patterns in the collected data.

The dashboard provides insights into respondents' job roles, salaries, satisfaction levels, technology preferences, and geographical distribution.

## Objectives

- Analyze survey responses to understand respondent demographics and professional backgrounds.
- Explore salary trends across different job roles.
- Understand satisfaction levels among respondents.
- Identify technology preferences and trends.
- Present key findings through interactive visualizations.

## Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculations and measures
- **Microsoft Excel** – Raw survey dataset

## Dashboard Features

- Survey response overview
- Salary analysis by job role
- Job role distribution
- Technology and programming language preferences
- Respondent satisfaction analysis
- Country-wise survey insights
- Interactive filters and visualizations

## Dataset

The project uses a survey dataset containing responses from approximately 630 participants.

The dataset includes information related to:
- Job roles
- Salaries
- Countries
- Satisfaction levels
- Technology preferences

## How to Use

1. Clone or download this repository.
2. Open `SURVEY DASHBOARD.pbix` using Power BI Desktop.
3. If prompted, update the source path to `RAW DATA.xlsx`.
4. Refresh the data if required.
5. Explore the dashboard using its interactive filters and visualizations.
